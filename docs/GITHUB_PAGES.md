# GitHub Pages

نسخة الويب من نفس تطبيق Expo.

بناء النسخة المخصصة لمسار المستودع:

```sh
npm ci
node scripts/export-github-pages.cjs
```

تُنشر محتويات `dist-pages/` في جذر فرع `gh-pages`. اختر هذا الفرع والمجلد `/ (root)` في Settings → Pages → Deploy from a branch. يحتوي التصدير على `.nojekyll` ونسخة `404.html` لتشغيل مسارات التطبيق عند إعادة التحميل. قد تعيد GitHub حالة HTTP 404 عند فتح مسار داخلي مباشرة رغم تشغيل التطبيق.

متغير `YALLA_WEB_BASE_PATH` يضبط المسار أثناء هذا البناء فقط. بناء الهاتف والموقع المستضاف على الجذر لا يستخدمانه.

حساب GitHub الحالي يتطلب مستودعًا عامًا أو ترقية الخطة لتفعيل Pages. لم تُغيّر خصوصية المستودع أثناء تجهيز النشر. نشر نسخة جديدة يحتاج إعادة البناء وتحديث فرع `gh-pages`؛ لا توجد مزامنة تلقائية حاليًا.
