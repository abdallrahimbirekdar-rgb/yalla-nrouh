# نسخة أندرويد للتجربة

النسخة التجريبية تحمل اسم «يلا نروح» ومعرف `com.yallanrouh.demo`، وتستخدم حسابات ورحلات محلية للتجربة. لا يوجد اتصال بسائقين حقيقيين.

## تجربة الوظائف

1. ثبّت ملف APK وافتح التطبيق.
2. اختر الإدارة ثم اعتمد السائق التجريبي.
3. من شاشة السائق، فعّل استقبال الطلبات.
4. من شاشة الراكب، اختر العناوين والفئة وأكد الطلب التجريبي.
5. عد إلى السائق لقبول الطلب وتسجيل الوصول.
6. افتح تفاصيل الرحلة في شاشة الراكب للحصول على رمز البدء.
7. أدخل الرمز في شاشة السائق، ثم ابدأ الرحلة وأنهها.
8. جرّب السجل والتقييم وتغيير اللغة وإعادة فتح التطبيق.

يمكن تجربة الموقع الحالي بعد الموافقة على إذن الموقع. خريطة OpenStreetMap تعمل بطلبك دون مفتاح Google. البحث بالعناوين يحتاج خادمًا، والإدخال اليدوي متاح. راجع LOW_CONNECTIVITY.md لاختبارات الإصدار 0.5.0.

## إعادة البناء

```bash
npm ci
npx expo prebuild --platform android --no-install
```

للبناء السحابي بعد ربط حساب Expo ومشروعه:

```bash
npx eas-cli@latest build --platform android --profile preview
```

للبناء المحلي باستخدام JDK 17 وAndroid SDK 36 وNDK 27.1.12297006:

```bash
cd android
./gradlew :app:assembleRelease -PreactNativeArchitectures=arm64-v8a -Pexpo.useLegacyPackaging=true
```

ملف الاختبار مبني لوحدات ARM64، ويحتوي شيفرة JavaScript داخله فلا يحتاج إلى Metro أو حاسوب قيد التشغيل. يستخدم إعداد توقيع الاختبار الموجود في القالب، ولا يُعتمد هذا التوقيع لنشر الإنتاج.

أضيف `scripts/patch-gradle-resolver.cjs` كخطوة `postinstall` لإصلاح مشكلة توافق معروفة بين React Native 0.83 وGradle 9 في إصدار Foojay resolver القديم. يطابق الإصلاح تحديث المرجع الرسمي إلى 1.0.0، ولا يغير وظائف التطبيق:

https://github.com/reactwg/react-native-releases/issues/1349

البناء وفحص توقيع APK لا يغنيان عن التجربة على هاتف فعلي.
