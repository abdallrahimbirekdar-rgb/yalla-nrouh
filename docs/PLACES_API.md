# Places service contract — خدمة البحث بالعناوين

الإصدار 0.2.0 يحتوي عميل اتصال مُجهزًا، وليس خادم بحث منشورًا. يظل حجز الرحلات تجريبيًا محليًا حتى عند ربط البحث.

## الإعداد

انسخ `.env.example` إلى `.env` واضبط `EXPO_PUBLIC_API_URL` إلى عنوان خادم HTTPS تملكه، دون اسم مستخدم أو كلمة مرور أو query string. مثال توضيحي فقط: `https://api.example.com`.

لا تضع مفاتيح خاصة أو رموز دخول مستخدمين في متغير يبدأ بـ `EXPO_PUBLIC_`؛ هذه القيم تدخل حزمة التطبيق. لم تُضمّن أي مفاتيح أو حسابات فعلية في المشروع.

## الطلب

```http
GET /v1/places/search?q=<encoded-address>&language=ar&region=1
Accept: application/json
```

- `q`: عبارة يكتبها المستخدم، 3–200 حرف. لا يوجد بحث تلقائي أثناء الكتابة؛ يُرسل الطلب عند الضغط.
- `language`: `ar` أو `en`.
- `region`: فهرس المحافظة في `regions` داخل `src/domain.ts`، من 0 إلى 13. هذا تلميح بحث، وليس تحقق تغطية جغرافيًا.
- لا يرسل عميل البحث Cookies أو رموز حسابات. يحتاج endpoint العام إلى حدود استخدام ومراقبة مناسبة على الخادم قبل إطلاقه.
- يجب إعداد CORS المناسب لمعاينة الويب. التطبيق لا يتبع تحويلات HTTP من endpoint البحث.

## الاستجابة

```json
{
  "places": [
    {
      "id": "provider-place-id",
      "label": "اسم المكان وعنوانه",
      "coordinate": { "latitude": 33.5138, "longitude": 36.2765 }
    }
  ]
}
```

الحد الأقصى 20 نتيجة. يجب أن يكون كل معرف فريدًا وأن تكون الإحداثيات محدودة وصالحة. يتحقق العميل من بنية النتيجة قبل عرضها، ويوقف الطلب بعد 12 ثانية. عدم وجود رابط خدمة يمنع إرسال أي طلب.

الخادم مسؤول عن ربط مزود الأماكن والخرائط، وحماية مفاتيحه، وسياسات الاستخدام، والتحقق من نطاق الخدمة في سوريا. صلاحية إحداثيات العالم وحدها لا تعني أن المنطقة مخدومة.

## خرائط الهاتف

- أندرويد: اضبط `GOOGLE_MAPS_ANDROID_API_KEY` في بيئة البناء. يضيف `app.config.ts` إعداد المزود عند وجوده. قيّد المفتاح بحزمة `com.yallanrouh.demo` الحالية وشهادة التوقيع، وغيّر المعرف عند تجهيز الهوية النهائية.
- آيفون: يُستخدم مزود Apple Maps الافتراضي.
- المعاينة عبر المتصفح: إدخال إحداثيات وGPS؛ لا تعرض خريطة تفاعلية.
- يطلب التطبيق إذن الموقع في المقدمة بعد ضغط المستخدم فقط. لا يطلب تتبعًا في الخلفية أو خدمة موقع دائمة.
- تحديد نقطة على الهاتف يُنسخ إلى مسودة الرحلة عند التأكيد فقط. تعديل عنوانها لاحقًا يزيل الإحداثيات القديمة لمنع عدم التطابق.

لم يُجر اختبار خرائط أو GPS على هاتف فعلي ضمن هذا الإصدار.
