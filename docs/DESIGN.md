# واجهة يلا نروح — 0.3.0

تصميم مستقل مستوحى من مرجع الصور الذي قدمه صاحب المشروع: تدرجات بنفسجية وزرقاء، أسطح داكنة ناعمة، وحضور بصري أوضح للأيقونات. تبقى يلا غو مرجع فئات الخدمة وأوبر مرجع تدفق الرحلة.

| العنصر | التنفيذ |
| --- | --- |
| خلفية التطبيق | كحلي داكن `#0b0e1b` مع تدرج علوي هادئ |
| الأزرار الأساسية | تدرج أزرق `#5269ed` إلى بنفسجي `#9161ec` |
| النص | أبيض مائل إلى الأزرق، مع تباين مرتفع للنص الثانوي |
| الخط | Cairo بأوزان عادي ومتوسط وعريض، محمل محليًا ضمن الحزمة |
| البطاقات | حواف مستديرة، أسطح شبه شفافة وحدود خفيفة |
| الرحلات | ست بطاقات في عمودين، مع أيقونات وعلامة اختيار واضحة |
| التنقل | شريط سفلي ثابت للراكب والسائق والسجل والإدارة التجريبية |
| نماذج العناوين | أيقونتان مختلفتان للانطلاق والوصول، وإبراز الحقل عند تحريره |
| الحالة | شارة بأيقونة ونص؛ لا يعتمد المعنى على اللون وحده |
| هوية التشغيل | أيقونة اتجاه مستقلة، ومظهر بدء داكن |

الهوية الأصلية قابلة للتحرير في `assets/brand-mark.svg`. لم تُنسخ صور الموقع المرجعي أو شعاراته إلى التطبيق.

تعمل الواجهة بالعربية والإنكليزية. جرى فحصها في المتصفح بعرض 320 و390 و768 بكسل، بما في ذلك شاشة الحجز وبطاقات الرحلات والسائق والإدارة.

هذا تحديث واجهة. تظل الرحلات والحسابات محلية للتجربة، وخدمات الخرائط والبحث الفعلية تحتاج الإعداد السابق الموثق.
