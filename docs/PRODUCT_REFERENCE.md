# Product reference — مرجع المنتج

تم اعتماد توجيه صاحب المشروع: **يلا غو أولًا، والاستفادة من أوبر**. تاريخ المراجعة: 2 نوفمبر 2026.

| المجال | المرجع | القرار في يلا نروح |
| --- | --- | --- |
| فئات السيارات | يلا غو + الأسماء التي حددها صاحب المشروع | ست فئات ظاهرة في شاشة الحجز |
| كلاسيك | موقع يلا غو | اقتصادي للمشاوير اليومية |
| كومفورت | موقع يلا غو | سيارات حديثة ومكيفة |
| تكسي أصفر | موقع يلا غو | تكسي عمومي للتنقل داخل المدينة |
| VIP | موقع يلا غو | سيارات فاخرة للأعمال والمناسبات |
| سيدات كلاسيك / كومفورت | الفئتان بطلب صاحب المشروع | موجودتان؛ الفرق الدقيق وشروط القبول غير مثبتة من مصدر رسمي منشور |
| أهلية السيارة | قائمة السيارات المقبولة في يلا غو | تُصمم لاحقًا حسب الشركة والموديل والسنة؛ لا يكفي سنة عامة لكل الفئات |
| ترتيب الحجز | أوبر | وجهة ثم فئة ثم مراجعة ثم تأكيد، مع إبراز الحالة التالية |
| مراحل السائق | أوبر | متاح، قبول، وصول، بدء، إنهاء؛ محاكاة محلية الآن |
| التحقق من بدء الرحلة | ميزة Verify Your Ride في أوبر | رمز من أربعة أرقام؛ محلي للتجربة فقط |
| وضوح التكلفة | أوبر | لا يُعرض رقم وهمي؛ يحتاج السعر إلى الخرائط وتسعيرة يقرها المشروع |
| مشاركة الرحلة | ميزات السلامة في أوبر | مشاركة ملخص تجريبي الآن؛ متابعة مباشرة لاحقًا |

## المصادر المباشرة

- يلا غو — الموقع الرسمي ووصف الفئات: https://yallago.net/ar
- السيارات المقبولة — شروط موديلات وسنوات محددة: https://yallago.net/ar/accepted-cars
- يلا غو — صفحة أندرويد: https://play.google.com/store/apps/details?id=ae.com.yalla.go.dubai.client&hl=ar
- أوبر — طريقة الحجز وإظهار السعر التقديري قبل التأكيد: https://www.uber.com/de/en/ride/how-it-works/
- أوبر — قبول الرحلات والتنقل في تطبيق السائق: https://www.uber.com/gb/en/drive/basics/how-to-take-trips/
- أوبر — صفحة السلامة ورمز التحقق: https://www.uber.com/de/en/ride/safety/

المراجعة اعتمدت على المصادر المنشورة، وليست فحصًا لكل شاشة في نسخة يلا غو المثبتة على هاتف. لا توجد بيانات مؤكدة هنا عن أسعار الفئات الست أو عمولات يلا غو أو قواعدها الداخلية.

## حدود الاقتباس من المرجعين

المرجعان يوجهان وظائف وتجربة الاستخدام، ولا يعني ذلك استخدام هويتهما أو الإعلان عن شراكة معهما. الأسعار وشروط تشغيل السائقين والسيارات في «يلا نروح» تحتاج قرارات مستقلة.
