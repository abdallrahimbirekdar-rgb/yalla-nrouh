## المسار الرئيسي

1. اختر موقعك الحالي أو نقطة انطلاق ضمن 500 متر منه.
2. اختر الوصول من الخريطة، بحث Google Places، أو الأماكن المحفوظة بحسابك.
3. سجّل الدخول؛ تبقى مسودة النقاط محفوظة أثناء الانتقال للدخول.
4. راجع طريق Google والأجرة التقديرية، ثم أكد إرسال الطلب إلى خادم المشروع.
5. تابع الطلب ورمز البدء ذي الستة أرقام في «رحلاتي».

الحساب واحد للموقع والتطبيق. تُحفظ الجلسة وتُجدّد عبر Supabase Auth، ولا تُحفظ كلمة المرور. توجد شاشة لإنشاء الحساب واستعادة كلمة المرور. روابط البريد تحتاج إعداد عناوين إعادة التوجيه المعتمدة في مشروع Supabase عند تغيير نطاق الموقع.

لوحة الإدارة محمية بدور مخزّن في الخادم، وليست بمقارنة البريد في واجهة المستخدم. تدير التسعيرة المشتركة واعتماد السائقين. حساب المالك المعتمد هو `abdallrahim.birekdar@gmail.com`. لا تمنح الواجهة العامة صلاحيات اعتماد أو تعديل أسعار محلية بديلة.

## Android والخرائط

النسخة الموحدة تدعم وضعي الراكب والسائق ومعماريتي ARM64 وARM32. موقع Android يستخدم GPS الأصلي عبر جسر رسائل محدود؛ لا يطلب إذن موقع ثانٍ من WebView. طلبات GPS المتزامنة مشتركة ومحدودة الزمن، والتسجيل في الخلفية غير مطلوب. يتلقى الموقع حالة ظهور التطبيق.

التغييرات العادية للواجهة تُنشر للموقع دون APK جديد. الإصدار 0.9.0 يحتاج APK جديدًا لأن تغليف Android يعالج انتظار فتح الصفحة وطلبات الموقع والرجوع. لا يحدث تحديث إجباري خلال طلب نشط أو مسودة غير مكتملة. يُسمح بتحديث العرض عند الصفحة الرئيسية إذا كانت النقطة الوحيدة هي الموقع التلقائي ولا توجد رحلة نشطة أو مشكلة حفظ.

## حساب الأجرة

`الأجرة = round((فتح العداد + كم × سعر الكيلومتر + دقائق × سعر الدقيقة) × معامل الذروة)`

خدمة `fare-route` المحمية تحسب طريق القيادة في Google وتعيد التسعيرة المشتركة. مفتاح Google Routes يبقى في أسرار Edge Functions؛ لا يُضمّن في ملفات الويب أو APK. تظل حدود استدعاء الخدمة مفعلة. الأجرة قبل الطلب تقديرية؛ لا توجد دفعات إلكترونية أو تسوية مالية نهائية مؤتمتة.

## التطوير والتحقق

```sh
npm ci
npm run typecheck
npm run lint
npm test
node scripts/export-github-pages.cjs
```

النشر إلى `main` يبني الموقع وينشره عبر GitHub Pages. تغييرات Android المعلنة في workflow تبني ملف APK موحدًا وتتحقق من التوقيع واسم الحزمة والإصدار قبل نشره في Release.

## حدود التشغيل

هذه **نسخة اختبار** تتصل بخادم حسابات وطلبات فعلي، وليست إعلانًا عن توفر خدمة سيارات تجارية. يلزم اعتماد السائقين والتشغيل الميداني. سجل الحركة/العداد المحلي القديم يبقى ضمن بيانات النسخ السابقة ولا يستخدمه مسار الحجز الرئيسي بدل طلبات الخادم.

نجاح الاختبارات الآلية والبناء لا يغني عن فحص APK على هاتف Android فعلي: GPS في مكان مفتوح وداخل مبنى، الأذونات المرفوضة، التحديث فوق نسخة سابقة، إغلاق التطبيق وفتحه، العودة من الخلفية، الشبكة الضعيفة، تسجيل الدخول والإدارة.
